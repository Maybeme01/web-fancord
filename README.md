# 🌟 FanCord — Modern Web Portal & Showcase

موقع متكامل، حديث، وفائق السرعة لأداة **FanCord** مع دعم ثنائي للغتين (العربية والانجليزية)، وتصميم زجاجي نيون يعكس هوية الشعار الرسمي، ودليل شامل وتفاعلي لجميع البلوقينات والإضافات الحصرية.

---

## 🚀 المميزات الرئيسية للموقع (Key Features)

- 🌐 **دعم كامل للغتين (العربية والانجليزية - Bilingual RTL / LTR):**
  - تحويل فوري بنقرة زر واحدة بين العربية (RTL مع خط Cairo) والانجليزية (LTR مع خط Plus Jakarta Sans).
  - عند اختيار اللغة الإنجليزية، تتحول الواجهة بالكامل بنسبة 100% دون أي نصوص عربية متبقية (بما في ذلك المحاكاة، الفئات، الأزرار، والبطاقات).
  - حفظ اللغة المفضلة للمستخدم تلقائياً في المتصفح (`localStorage`).

- 💎 **الإضافات الحصرية لـ FanCord (Exclusive FanPlugins):**
  - قسم مخصص وبارز يحمل شارة VIP النيون يعرض جميع الإضافات الحصرية مع شرح واضح ومختصر:
    1. **FanToolsAll**: جناح كشف الفيك ديفن (Fake Deafen) وبصمات النسخ المعدلة عبر 6 محاور كشف بروتوكولية وصوتية حتمية.
    2. **FastPing**: تحويل معرف المستخدم (User ID) المكتوب في الدردشة فوراً إلى إشارة منشن `<@ID>` بنقر مزدوج.
    3. **OBSRemoteControl**: التحكم في بث OBS Studio والتسجيل والمشاهد وReplay Buffer مباشرة من ديسكورد عبر WebSocket.
    4. **Questify**: إكمال تلقائي لمهام ديسكورد (Discord Quests)، تسريع مهمات الفيديو، وإزالة الإعلانات والبنرات الترويجية.
    5. **TikTokViewer**: لوحة جانبية لمشاهدة وتصفح تيك توك داخل ديسكورد مع حفظ تسجيل الدخول وسلايدر الصوت.
    6. **VoiceLogger**: سجل متطور للرومات الصوتية لتتبع الدخول والخروج مع فلاتر مستخدمين وسيرفرات وواجهة عربية.
    7. **VoiceRoomRecorder**: تسجيل فيديو وصوت عالي الدقة للروم الصوتي مع إظهار أسماء وصور وتحدث الأعضاء وحفظ تلقائي في Videos/FanCord.
    8. **CustomRPC**: تخصيص نشاط وحالة ديسكورد (Rich Presence) بأزرار وروابط وصور مخصصة ومعاينة حية.
    9. **ArabicUI Engine**: محرك التعريب الكامل ودعم RTL وتخصيص الخطوط وإعدادات اللغة الشاملة.

- 📚 **دليل شامل لجميع الإضافات (Catalog of 494 Plugins):**
  - فحص واستخراج دقيق لكافة الإضافات من المجلد الأصلي للأداة (`src/fanplugins` و `src/plugins` و `src/equicordplugins`).
  - العدد الإجمالي الدقيق: **494 إضافة** جاهزة للاستخدام.
  - كل إضافة مشروحة باختصار ودقة باللغتين العربية والإنجليزية.
  - محرك بحث فوري وسريع (Live Filter) يبحث في الأسماء والأوصاف.
  - فلاتر الفئات:
    - الكل (494)
    - ⭐ إضافات حصرية (FanPlugins)
    - 🎙️ الصوت والرومات
    - 🛡️ الأمان والخصوصية
    - 💬 الدردشة والرسائل
    - 🎬 الوسائط والتكاملات
    - ✨ النيترو والتخصيص
    - 🎨 الواجهة والمظهر
    - ⚙️ أدوات مساعدة
  - زر نسخ فوري لاسم الإضافة ونافذة تفاصيل منبثقة (Modal).

- ⚡ **طرفية تفاعلية ودليل التثبيت (Interactive Terminal & Setup):**
  - تبديل سهل بين أوامر التثبيت: `pnpm inject`، `Discord Stable`، `Discord Canary`، والبناء من المصدر.
  - زر نسخ الأوامر بنقرة واحدة مع إشعارات منبثقة (Toast).

- 🎨 **حركات وتأثيرات بصرية متقدمة (Animations & Aesthetics):**
  - خلفية شبكية متحركة تفاعلية بالـ Canvas (`#bg-canvas`) متناسقة مع ألوان الشعار البنفسجي والوردي النيون.
  - محاكاة حية لواجهة ديسكورد مع تنبيه كشف الفيك ديفن المباشر.
  - تأثيرات زجاجية (Glassmorphism) وبطاقات ترتفع بسلاسة عند التمرير.
  - جدول مقارنة تفاعلي مع ديسكورد العادي وبدائل التعديل الأخرى.
  - قائمة أسئلة شائعة تفاعلية (FAQ Accordion).

## 💻 طريقة التشغيل والمعاينة (How to Run)

يمكنك معاينة الموقع وتشغيله بأي خادم ويب محلي:

```bash
python -m http.server 3000
```
ثم افتح المتصفح على: `http://localhost:3000`

أو فتح [index.html](index.html) مباشرة في أي متصفح.
